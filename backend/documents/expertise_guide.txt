## Task Assignment Guidelines

When assigning tasks, consider:

1. **Skill Match**: Match required technical skills with team member expertise
2. **Workload**: Check current workload to ensure capacity
3. **Complexity**: Senior developers for complex architectural decisions
4. **Timeline**: Consider expertise level for time-sensitive tasks
5. **Learning Opportunities**: Sometimes assign tasks for skill development

### Example Task Assignments:

**"Build a user authentication API with JWT"**
- Best Match: Alice Johnson (Senior Backend Developer)
- Skills: Python, FastAPI, Security, PostgreSQL
- Reason: Expert in backend API development and security

**"Create a dashboard with charts and real-time updates"**

**"Set up Kubernetes cluster for microservices"**
